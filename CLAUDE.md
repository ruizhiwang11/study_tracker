# Study Tracker — CLAUDE.md

This repo tracks daily C++/OS/HFT systems study during a structured rebuild period.

## Goals
- Deep C++ mastery: memory model, concurrency, templates, move semantics, CRTP, policy design
- OS/systems: x86, RISC-V, boot, virtual memory, scheduling, syscalls, kernel bypass
- HFT-relevant systems: cache/NUMA, CPU affinity, lock-free structures, low-latency networking, exchange protocols
- Interview readiness: algorithms, LeetCode, system design, C++ trivia
- Rebuild strong resume bullets from prior work (HKEX market layer, FPGA integration, exchange connectivity, ring buffers, branchless processing)

## Subdirectories
- `daily/` — one file per day: YYYY-MM-DD.md
- `topics/` — running notes per subject (cpp.md, os.md, networking.md, hft.md, algorithms.md)
- `retrospectives/` — weekly review every Sunday
- `my_cpp/` — hands-on C++ practice code
- `my_os/` — OS/hardware experiments

## Daily file update rule
Every session, update or create `daily/YYYY-MM-DD.md` with:
- What was studied
- Key insight(s)
- Code practiced (link to files in my_cpp/ or my_os/)
- Weak points identified
- Plan for next session

Update the relevant `topics/*.md` file when a concept is learned or solidified.

## Style
- Concise technical notes, not prose
- Prioritize depth over breadth
- Track weak points honestly — they drive the next session
